#  Telegram Raffle Bot

Бот для проведения розыгрышей призов и выдачи промокодов от партнеров фестиваля. Реализует механику ежедневных розыгрышей, накопления шансов на главный приз и автоматического определения победителей.

##  Возможности
-  **Промокоды:** Выдача уникальных промокодов (лимит 1 в день на партнера), защита от повторной выдачи.
-  **Ежедневные розыгрыши:** Проверка подписки на канал партнера перед участием.
-  **Геймификация:** Накопление шансов на главный приз за каждый активный день (максимум 10).
-  **Финальный розыгрыш:** Случайный выбор победителей с учетом веса накопленных шансов.
-  **Безопасность и админка:** Сбор контактов победителей через FSM, встроенная статистика и команды для администратора.

##  Стек технологий
- **Язык:** Python 3.11+
- **Библиотека:** aiogram 3 (асинхронность, FSM, роутеры)
- **База данных:** SQLite (хранение пользователей, промокодов, шансов и победителей)
- **Конфигурация:** python-dotenv
